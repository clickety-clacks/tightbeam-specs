## Architecture

### Change shape

Create one candidate commit on a non-protected branch from the exact target base. Apply
the inverse of `7ae16ed4` only to the Reconciliation File Set. The candidate therefore
restores the four pre-`7ae16ed4` blobs while leaving later disjoint work in place.

Deletion is the selected closure. Adding loses because a replacement threshold would
invent policy and create another textual home. Accepting loses because the product owner
explicitly rejected the effect.

The candidate uses one mutation seam: one commit containing the four-file deletion.
Protected integration is the only remote mutation seam.

### Canonical homes

The code repository remains the canonical textual home for guidance. This target spec
states required byte outcomes and rationale. It does not copy replacement guidance into
the specs repository.

Operating pattern taught by this change: **none**. The change deletes a rejected policy
exception and introduces no capability or command, so it needs no operating-manual
amendment.

### Verification flow

1. The producer fetches the target branch and the two locked `0.1.8` refs in an owned
   clone.
2. The producer proves the preconditions and records the baseline package gate.
3. The producer creates the four-file candidate and records its exact commit.
4. The producer runs the local package gate and inspects the built KungFu bytes.
5. A different session performs one exact-revision independent review against this
   spec’s path and SHA-256.
6. The product owner assigns a third-session Integration holder after the candidate
   receives `reviewed-clean`.
7. The Integration holder records successful `linux` and `macos` pull-request jobs for
   the exact reviewed candidate head SHA, then merges through the protected pull-request
   process.
8. The Integration holder reads back the fetched remote SHA, the exact-SHA workflow,
   and both platform packages.
9. The Integration holder records a reverse-application simulation. The holder does
   not execute a rollback without separate authority.
