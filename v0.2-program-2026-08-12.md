## 2. Substrate guidance for ALL agents (anatomy)

A neutral-seed guidance set that teaches every agent — any archetype, any
kungfu — how to USE the substrate: which verb for which situation, with
worked examples (when to file a work-item vs bare wake; how to thread
assignments; when an attest vs a message; how to read toplines before asking;
how to file a decision-request; how to publish standing directives). Upgrade
path for the informal .md that ships today. Deliverable: `guidance/
using-the-substrate.md` in the neutral seed, example-driven, one page per
verb-family. Test: a fresh agent given only this guidance performs a clean
work-item→assign→attest→complete cycle unprompted.

## 3. Per-archetype substrate playbooks + backstop rails (culture)

For the engineering kungfu: each archetype (coder, reviewer, spec-writer,
product-owner, recon, exec) gets a playbook section — how THIS role
manipulates the substrate to do its job (a reviewer's verdict discipline; a
coder's progress/artifact cadence; a PO's rumination verbs; an exec's
delegation-card operations). Rails are then MODIFIED OR ADDED to backstop each
playbook — the rail encodes the floor of the discipline the playbook teaches
(playbook = should; rail = must-not-fall-below). Deliverable per archetype:
guidance fragment + its backstop statute, shipped together, reviewed together.

## 4. Model defaults + ringdown (TOML upgrade)

Today: archetype defaults exist informally (.md with the substrate, one per
kungfu; spawn inherits archetype defaults). Upgrade: a structured `ringdown`
field in archetype manifests (TOML) — an ORDERED list of model elections,
e.g. day-to-day = codex/Sol tiers, ultimate smarts = Fable, fallback =
sol[xhigh]. Spawn semantics: model unspecified → walk the ringdown
deterministically against live catalog availability/quota; record which rung
was chosen and why; caller override always wins; list exhausted → NAMED
FAILURE, never a silent substitute.

**Adjudication boundary, pinned (this is not the deleted machinery):**
selection happens at CREATION time only, as a deterministic function of
(org-authored ordered preference × live catalog truth), recorded, overridable
— physics executing culture, like rails. What stays forbidden: mid-session
substrate model-switching, holds pending model decisions, escalation ladders
about model choice. A mid-session model failure still fails the turn by name;
an AGENT reads the failure and the ringdown guidance and decides (respawn,
different rung, refuse). The 2026-08-05 ruling's three duties are untouched.

## 7. Who watches the watchers — the tenet auditor ("Miller")

A smart agent + read-only Tightbeam database + this heuristic set. Its job is
DOUBLE-SIDED: find where the implementation fails the tenets, AND find
whether correct implementations produce the predicted effects — evidence FOR
the theories and evidence AGAINST them. A tenet with no way to lose is not a
tenet; each check below states what refutation would look like.

**Conformance probes (tenet → falsifiable DB check):**
- C1 Lawful exits: enumerate stuck states (open assignments/items/requests
  quiet past floor) and verify an agent-reachable verb could move each. Any
  state whose only exit is admin/DB surgery = FINDING (the wi_1b0237fe class).
- C2 Holder-filed doctrine: lifecycle attests (progress/completion/surrender)
  filed by non-holders = zero, or FINDING.
- C3 Substrate never judges: no substrate-attributed row that encodes a
  choice among alternatives (model, holder, priority) absent org-authored
  policy naming it.
- C4 Truth completeness: every digest/summary row's members exist as source
  rows (post-fabric: Law 2 audit — attenuation lost information = FINDING).
- C5 Wake integrity: zero empty prompts; zero wakes whose exit condition is
  a decision rather than time/turn-boundary.
- C6 Named failure: sample failed turns — each carries a precise reason
  (bare :task_crash-class opacity = FINDING).

**Effect evidence (theory → measurable prediction → confirm/refute):**
- E1 Attention economics: share of frontier-model turns spent on
  coordination-class traffic. PREDICTION: falls after front desks; if desks
  ship and it doesn't fall, the fabric theory is wrong or the impl is.
- E2 Avasarala precision: prod false-positive rate (prod issued ≤N min after
  a progress attest = false positive). PREDICTION: retargeting to desks cuts
  the COST of false positives ~10-100× even if the rate holds.
- E3 Spirit throughput: PO turns filing spirit/rumination verdicts vs
  coordination turns. PREDICTION: ratio inverts after the pilot.
- E4 Floor guarantee: zero open obligations quiet past the Avasarala floor
  without an escalation row. Any miss REFUTES the deterministic-backstop
  theory and is a sev-1 on the fabric.
- E5 Exception-based reporting adherence: routine progress landing as
  attest-only vs upstream messages. PREDICTION: bones make the discipline
  near-universal; low adherence with bones live = bones misconfigured.
- E6 Correlated-failure signature: identical wrong outcomes clustered by one
  rule (bone misfire — fix the table) vs scattered (inference noise — tune
  guidance). The signature TELLS you which tissue failed.
- E7 Decimation drill (staged, not passive): retire a session mid-flight;
  measure whether the org degrades to a working topology without human
  repair. PREDICTION: agent-first orgs recover; each unrecoverable case
  names a missing exit (feeds C1).
- E8 Zombie rate: staffed-never-attested cards (26 today) trend to ~zero
  under desk triage; a stable zombie population = the fabric isn't reaching
  staffing hygiene.

Output contract: an evidence ledger per run — tenet, verdict
(CONFIRMS/REFUTES/GAP), cited rows, effect sizes where measurable. Refutations
are the prize, not the embarrassment: they're the only way the philosophy
stays empirical instead of becoming liturgy.
