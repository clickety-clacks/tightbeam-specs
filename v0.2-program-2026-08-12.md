## 7. Who watches the watchers — the tenet auditor ("Miller")

A smart agent + read-only Tightbeam database + this heuristic set. Its job is
DOUBLE-SIDED: find where the implementation fails the tenets, AND find
whether correct implementations produce the predicted effects — evidence FOR
the theories and evidence AGAINST them. A tenet with no way to lose is not a
tenet; each check below states what refutation would look like.

**r5 posture (CR-001 item 4): formalize Miller, never build him.** The
reference implementation already runs (the 0.1 churn-detection auditor;
the 2026-07-30 sample-then-act and topology-probe audits; the
forged-verdict catch as a live refutation probe). What ships is a SEED
PLAYBOOK — the tenet-audit discipline with three duties (conformance
probing; effect evidence; promotion/demotion scouting with the
shipped-vs-emergent razor as rubric) and an EMPTY probe list (fabric §13
Phase 5b). Everything below — C1–E8, the parameters, the seeds — is THIS
program's local casebook content and never ships.

**Parameter protocol (fold, 2026-08-13):** the seed values below bind run
№1; changing them is a recorded ledger entry, so runs stay comparable.
Windows: each run covers the 14 days before it unless stated.

**Conformance probes (tenet → falsifiable DB check):**
- C1 Lawful exits: enumerate stuck states (open assignments/items/requests
  quiet past floor — seed floors per fabric §5: 30 min for unanswered
  `input-needed`/`blocker`, 60 min attest-quiet for open obligations) and
  verify an agent-reachable verb could move each. Any state whose only
  exit is admin/DB surgery = FINDING (the wi_1b0237fe class).
- C2 Holder-filed doctrine: lifecycle attests (progress/completion/surrender)
  filed by non-holders = zero, or FINDING. (Directive-kind attests by a
  delegation card's named principal are lawful — fabric §4 scoping.)
- C3 Substrate never judges: no substrate-attributed row that encodes a
  choice among alternatives (model, holder, priority) absent org-authored
  policy naming it. (An `elections` walk citing its manifest is org-authored
  policy named; an unrecorded or uncited selection = FINDING.)
- C4 Truth completeness: every digest/summary row's members exist as source
  rows (post-fabric: Law 2 audit — attenuation lost information = FINDING).
- C5 Wake integrity: zero empty prompts; zero wakes with NO scheduled exit
  (time or turn-boundary). Distinguish (fold): a SUBSTRATE-imposed wait
  with no scheduled exit = FINDING; an agent holding lawful exits and
  CHOOSING to wait on a decision-request it filed = lawful election, not a
  finding (the effort-without-effect rail notices idleness).
- C6 Named failure: sample failed turns — each carries a precise reason
  (bare :task_crash-class opacity = FINDING).

**Effect evidence (theory → measurable prediction → confirm/refute):**
- E1 Attention economics: share of frontier-model turns spent on
  coordination-class traffic, measured on classed rows (post-Phase-1 only —
  earlier rows are unclassifiable and the 0.1.x/0.2 split confounds them).
  PREDICTION: falls after front desks vs the Phase-3 before-window; if desks
  ship and it doesn't fall, the fabric theory is wrong or the impl is.
- E2 Prodder precision: prod false-positive rate (prod issued ≤5 min
  after a progress attest = false positive; seed N=5). PREDICTION:
  retargeting to desks cuts the COST of false positives ~10-100× (cost
  unit: the prodded session's per-turn token price) even if the rate holds.
- E3 Spirit throughput: PO turns filing spirit/rumination verdicts vs
  coordination turns. PREDICTION: ratio inverts after the pilot.
- E4 Floor guarantee: zero open watermark-population members quiet past
  their prodder floor (fabric §5 seed floors) without an escalation row. Any miss REFUTES the
  deterministic-backstop theory and is a sev-1 on the fabric.
- E5 Exception-based reporting adherence: routine progress landing as
  attest-only vs upstream messages. PREDICTION: bones make the discipline
  near-universal (≥90% of routine progress attest-only); adherence <50%
  with bones live = bones misconfigured.
- E6 Correlated-failure signature: identical wrong outcomes clustered by one
  rule (bone misfire — fix the table) vs scattered (inference noise — tune
  guidance). Refutation condition (fold): the signature fails if a
  rule-clustered failure persists after the table fix, or a scattered
  pattern clears when one table changes — either observation refutes the
  diagnostic and is recorded as such.
- E7 Decimation drill (staged, not passive): a session is retired mid-flight
  and the org's degradation measured. Safety contract (fold): Miller
  PROPOSES the drill (target, blast radius, live obligations at risk); Mike
  or the PO authorizes; a staged exercise executes it via lawful retirement
  verbs in pilot scope only — Miller itself never retires anyone.
  PREDICTION: agent-first orgs recover to a working topology without human
  repair; each unrecoverable case names a missing exit (feeds C1).
- E8 Zombie rate: staffed-never-attested cards (26 at the 2026-08-12
  baseline) trend to ≤2 under desk triage; a population unchanged ±10%
  across two consecutive runs = stable = the fabric isn't reaching staffing
  hygiene.

**Third duty (added 2026-08-13, Mike's ruling): promotion scouting.**
Beyond conformance (C) and effect evidence (E), Miller watches the rows for
institutions the org invented — practices with no handbook origin — and
adjudicates them with the shipped-vs-emergent razor
(emergent-formalization-candidates-2026-08-13.md): contentless floors are
proposed for substrate, proven domain-free shapes for seed with content
stripped, local scar tissue named and left alone. The mirror duty is
demotion scouting: shipped seed content no org adopts, and casebook entries
whose hit counts went quiet after a change. Promotion requests are a
standard Miller output artifact; the 2026-08-13 candidates doc is the
reference example of one.

Output contract: an evidence ledger per run — tenet, verdict
(CONFIRMS/REFUTES/GAP), cited rows, effect sizes where measurable, the
parameter set used. Refutations are the prize, not the embarrassment:
they're the only way the philosophy stays empirical instead of becoming
liturgy.

## 8b. Repo governance (RULED 2026-08-13: no door — signs, law, tripwire, trust)

The PR requirement and its successors are ABOLISHED. Discovery that forced
the question: GitHub does not enforce branch protection or rulesets on
private repos under the free plan — it accepts the config and ignores it.
The "lock" installed at the flip was a prop, proven by test (an unstamped
push landed; the empty `door test` commit on main is the honest record of
that discovery). A prop lock manufactures unearned confidence — worse than
no lock. Mike then decooked the replacement designs (trailer ruleset, local
bare origin + pre-receive, `land` ceremony) down to nothing, on the correct
observation that agents are extremely well trained to stay in their git
lane; the only real hazard is an OBEDIENT agent holding a STALE MAP.

The protection is therefore:
- **Signs**: each line's AGENTS.md/CLAUDE.md names the line and its
  integration rule (main's live; 0.1.x's awaits their election of
  `docs/line-identity-0.1.x` — the one-line fix that retires the stale map).
- **Law**: gates-before-push per the repo's own verification section;
  main's writers are law-bound program agents.
- **Tripwire**: GitHub CI runs on every main push — a stray landing is
  visible immediately and reverted in minutes; git forgets nothing.
- **Trust**: agent-first applied to git — the org runs on judgment and law,
  not locks. Revisit ONLY on evidence: if a stray merge ever happens, build
  precisely the lock that would have stopped it.

GitHub's role (unchanged from the 2026-08-13 scoping): CI matrix, releases,
distribution. It is not where pushes are judged — nothing is, by design.

- **Election test (REVISED 2026-08-13, Mike's three-bin law — supersedes

  or work item) is triaged into one of three bins:
  1. **ORTHOGONAL** to the 0.2 focus (ordinary fixes, unrelated subsystems):

     tickets also merge to main, cherry-picked in the same sitting. Keeps
     main from rotting behind on general health.
  2. **RELATED** to fabric-touched territory: an agent assesses
     compatibility and value for the new system, then either applies the
     commit as-is, or writes 0.2's OWN VERSION of the change, or rejects
     with the reason recorded. Never a blind cherry-pick into re-legislated
     ground.
  3. **NEEDS ADJUDICATION** (can't be judged yet — e.g. touches ground the
     fabric hasn't implemented): written to the DEFERRED LEDGER below and

  The old by-need citation rule survives inside bin 2 as the value test.
